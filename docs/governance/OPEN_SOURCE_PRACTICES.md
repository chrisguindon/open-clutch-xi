# Open-source practices (Eclipse-inspired)

**Audience:** the maintainer and contributors who care about licensing, IP and governance.

Open Clutch XI is an **independent personal project**. It is **not** an Eclipse Foundation project, isn't governed by the Eclipse Foundation Development Process, and has had no Eclipse Foundation review, approval or IP clearance. It voluntarily adopts practices from the **Eclipse Project Handbook** (https://www.eclipse.org/projects/handbook/) where they fit a small community project.

This table records each practice, how the repository implements it, and what remains. "Adopted voluntarily" means we follow the practice by choice. "EF-only" marks requirements that only apply to official Eclipse projects, which we don't claim to meet.

## Provenance and licensing questions for a human

Automated checks can't establish provenance. Before a release, the maintainer should confirm:

1. **AI-assisted code.** Generating it was consistent with the tools' terms. The maintainer reviewed it, and is satisfied it doesn't reproduce third-party code.
2. **Assets.** The CC0 assets (Quaternius, ambientCG, Freesound) were obtained from the stated free tiers and pages. Their licence files are kept locally in `asset-src/`.
3. **Portrait.** The creator portrait is the maintainer's own image and stays excluded from the EPL.

None of this repository's documentation claims legal approval or formal Eclipse compliance.
