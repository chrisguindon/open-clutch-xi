# CLAUDE.md

The instructions for working in this repository are in **[AGENTS.md](AGENTS.md)**. Read it and follow it. It is the single source of truth for all coding assistants and agents, so this file deliberately doesn't repeat any rules. How code is written (headers, TSDoc, comments) is in [docs/development/CODING_STANDARDS.md](docs/development/CODING_STANDARDS.md), linked from AGENTS.md. Its Git authorship policy applies to Claude Code too: commits use only the human's own configured Git identity, and `.claude/settings.json` keeps Claude Code's automatic commit and PR attribution off (a project preference; other tools' trailers are allowed).
